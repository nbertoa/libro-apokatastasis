# Libro Apokatastasis

Libro cristiano en desarrollo sobre la restauración universal.

El proyecto busca evaluar, paso a paso, el caso bíblico, histórico, filosófico y teológico a favor de la restauración universal, sin asumir de antemano que universalismo, infernalismo o aniquilacionismo sean verdaderos.

## Método

El manuscrito avanza principalmente mediante preguntas y respuestas. Cada conclusión importante debe considerar:

- la evidencia principal;
- el mejor argumento a favor;
- la mejor objeción;
- la mejor respuesta disponible;
- qué evidencia podría mostrar que la conclusión es equivocada.

La Biblia es la fuente central del argumento. La investigación especializada sirve para aclarar los textos, no para reemplazarlos.

## Estructura

- `manuscrito/`: capítulos del libro.
- `investigacion/`: notas de trabajo y análisis que no necesariamente pertenecen al texto final.
- `decisiones/`: criterios editoriales, decisiones metodológicas y cuestiones abiertas.

Los libros y artículos de investigación en PDF no se almacenan en este repositorio.
