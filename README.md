# Libro Apokatastasis

Libro cristiano en desarrollo sobre la restauración universal. El objetivo es construir y auditar el caso más fuerte posible sin asumir de antemano que universalismo, infernalismo o aniquilacionismo sean verdaderos.

## ¿Cómo se escribe el libro?

Principalmente mediante **pregunta → respuesta → siguiente pregunta**. Cada paso debe ganarse, las objeciones fuertes deben presentarse en su mejor forma y la Biblia ocupa el centro del argumento.

## ¿Dónde está cada cosa?

- `manuscrito/`: capítulos del libro, cada uno en archivo separado.
- `proyecto/`: directivas, estado actual, hoja de ruta, decisiones y preguntas personales.
- `skills/`: métodos operativos reutilizables para redactar y auditar.
- `investigacion/`: notas propias de investigación que conviene conservar.
- `ESTRUCTURA_REPOSITORIO.md`: mapa canónico de carpetas y archivos.
- `AGENTS.md`: punto de entrada para continuar el trabajo desde un chat o agente nuevo.

Los PDFs y libros completos de investigación no se almacenan en Git; permanecen en las Fuentes/biblioteca del Proyecto.
