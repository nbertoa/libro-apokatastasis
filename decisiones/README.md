# Decisiones del proyecto

Este directorio registra las decisiones metodológicas y editoriales del libro para que el razonamiento detrás de los cambios no se pierda con el tiempo.

Aquí se documentarán, entre otras cosas:

- criterios editoriales;
- estructura general del libro;
- decisiones de terminología;
- cuestiones todavía abiertas;
- cambios importantes de enfoque y la razón de esos cambios.
