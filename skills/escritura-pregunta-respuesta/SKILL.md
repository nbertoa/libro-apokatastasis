# ¿Para qué sirve esta skill?

Para escribir, reescribir o auditar capítulos del libro sin perder su forma argumental. La investigación puede ser compleja; la lectura debe ser simple.

# ¿Cuál es la regla central?

Cada sección debe hacer una sola pregunta real, responder una idea principal y dejar preparada la pregunta siguiente. El lector no debe necesitar un salto lógico grande.

# ¿Qué debe hacerse antes de redactar una respuesta?

1. Formular una sola pregunta.
2. Identificar la evidencia principal.
3. Construir el mejor argumento favorable.
4. Construir la mejor objeción.
5. Intentar responderla sin proteger la teoría.
6. Decidir internamente si la conclusión está establecida, es probable, posible, indeterminada o abierta.
7. Traducir sólo lo necesario a palabras simples.
8. Convertir la dificultad restante en la siguiente pregunta.

# ¿Cómo debe escribirse la respuesta?

- Usar lenguaje cotidiano.
- Mantener una idea principal.
- Incluir referencias bíblicas cuando corresponda.
- No introducir griego, filosofía o historia si no cambian algo importante para el lector.
- No usar autores como estructura narrativa; son herramientas de investigación, salvo cuando el autor mismo sea objeto histórico.
- No decir más de lo que la evidencia permite.
- No resolver una tensión antes de haberla examinado.
- No convertir una analogía en prueba.

# ¿Cómo se controla el sesgo?

Para cada conclusión importante preguntar:

- ¿Cuál es la mejor razón para pensar que estamos equivocados?
- ¿Qué evidencia nos obligaría a cambiar de opinión?
- ¿Estamos usando una definición que ya contiene la conclusión?
- ¿Estamos tratando una posibilidad como si fuera una demostración?
- ¿La posición rival puede explicar este mismo dato de manera razonable?

# ¿Cómo deben funcionar las transiciones?

La última dificultad relevante de una respuesta debe producir la siguiente pregunta. Evitar frases del tipo «además hay otro tema» cuando puede mostrarse por qué el nuevo problema nace del anterior.

# ¿Cómo se audita un capítulo ya escrito?

Comprobar, en este orden:

1. ¿Cada encabezado principal es una pregunta?
2. ¿Cada pregunta resuelve una sola dificultad?
3. ¿Cada respuesta contesta realmente esa pregunta?
4. ¿La siguiente pregunta nace de la respuesta anterior?
5. ¿Hay saltos lógicos?
6. ¿Hay afirmaciones más fuertes que la evidencia?
7. ¿Se presentó la mejor objeción disponible?
8. ¿Se distingue entre juicio real y la interpretación de su resultado final?
9. ¿Se conservan las tensiones bíblicas reales?
10. ¿El lenguaje puede simplificarse sin perder precisión?
