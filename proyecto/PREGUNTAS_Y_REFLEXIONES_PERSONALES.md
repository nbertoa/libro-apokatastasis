# ¿Qué preguntas y reflexiones personales queremos conservar?

Este archivo guarda preguntas, intuiciones y problemas que surjan durante el proyecto y que todavía no pertenezcan a un capítulo concreto. Sirve como insumo para investigación y auditoría, no como evidencia por sí mismo.

## ¿Cómo agregar una entrada?

Usar, cuando sea posible, este formato:

### ¿Pregunta o reflexión?

- **Origen:** Nico / investigación / lectura / objeción.
- **Por qué importa:** una o dos frases.
- **Dónde podría entrar:** capítulo o tema, si ya se sabe.
- **Estado:** abierta / investigando / incorporada / descartada.
- **Notas:** lo mínimo necesario.

---

## ¿Qué preguntas están abiertas ahora?

Todavía no se registraron preguntas personales adicionales. Agregarlas aquí cuando aparezcan, incluso si todavía no sabemos si terminarán en el manuscrito.
